✨ Sobre a Kimori

Kimori System é um bot multifuncional para WhatsApp, desenvolvido com "Baileys" (https://github.com/WhiskeySockets/Baileys).

Criada para automatizar tarefas, moderar grupos e proporcionar entretenimento, a Kimori reúne diversas funcionalidades em um único sistema.

🚀 Principais funcionalidades

- 🎮 Sistema de RPG e minigames.
- 🛡️ Moderação avançada de grupos.
- 🎨 Criação e conversão de figurinhas.
- 💰 Sistema de economia virtual (Kimocoins).
- 🤖 Inteligência artificial conversacional.
- ⚙️ Automação de comandos e tarefas.
- 💬 Suporte para grupos e conversas privadas.

---

⚙️ Instalação

1. Clone o repositório:

```git clone https://github.com/MatheussDevK/Kimori-Bot.git```

2. Acesse a pasta:

```cd Kimori-Bot```

4. Inicie a Kimori:

```npm start```

---

📱 Como usar

Após iniciar o projeto, conecte sua conta do WhatsApp seguindo as instruções de autenticação.

Prefixo padrão: "/"

```/menu```

Exibe o menu com todos os comandos disponíveis.
